# NOVA UI 更新

设计方向：深色宽侧栏、浅灰工作区、靛紫强调色、低对比边框与圆角卡片。NOVA 是可替换的展示品牌，不改变业务接口。

参考：Linear 官方设计更新 https://linear.app/now/behind-the-latest-design-refresh ，借鉴安静的导航与清晰的内容层级，不复制其素材。

修改范围：全局导航、顶部页签、经营概览、通用表格/筛选/表单样式；概览继续使用 `/api/v1/dashboard`，不嵌入虚构业务数值。未修改数据库或后台业务规则。

验证：JS 语法检查、24 项后台测试、`node tests/test_nova_theme.cjs` 展示层冒烟测试。浏览器工具拒绝本地 URL，尚未完成本轮桌面/手机视觉验收及点击回归，不能将代码检查当成视觉验收。

刷新本地首页查看新主题；若旧缓存未更新，可强制刷新。样式文件最后加载，后续可在 `nova-theme.css` 调整配色和密度，在 `nova-theme.js` 调整概览布局。
