# ERP frontend snapshot

Source: https://47.107.76.124/lingxing-erp/
Captured: 2026-10-13 (Asia/Shanghai).

The lingxing-erp directory contains the public HTML, CSS, JavaScript and API contracts. Backend source, database and credentials are not included. Business operations require the original API or a replacement backend.

Preview from the repository root: python -m http.server 5186 --bind 127.0.0.1 --directory reference
Then open http://127.0.0.1:5186/lingxing-erp/ . Without a backend, login and data operations will fail.

REA supports website and JavaScript analysis: https://github.com/morluto/rea . It was evaluated but not installed; the frontend files were directly downloadable.
